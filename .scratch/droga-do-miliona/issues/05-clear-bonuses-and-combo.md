# 05 — Ujednoznacznić bonusy i combo

**What to build:** Zastąpić abstrakcyjne glify i gwiazdy specjalnymi paczkami o jasnej nazwie, funkcji i informacji zwrotnej oraz przenieść komunikację combo do HUD.

Blocked by: 04

Status: ready-for-agent

- [x] Specjalne przedmioty mają rozpoznawalne formy i etykiety `BONUS`, `AUDYT`, `2× PUNKTY` oraz `OCHRONA 48 M`.
- [x] Pierwsze zebranie każdego rodzaju pokazuje jedno krótkie objaśnienie jego działania.
- [x] `BONUS` daje 350 punktów i pokazuje `+350 pkt`; zwykła paczka nadal daje 100 punktów.
- [x] Combo jest widoczne jako `SERIA ×N`, a czysta seria może dodawać jedynie subtelne firmowe smugi ruchu.
- [x] Iskra przy kurierze, czerwone gwiazdy i wszystkie pięcioramienne gwiazdy znikają z pickupów, HUD, nagród i dekoracji.
- [x] Specjalne paczki korzystają z tych samych reguł bezpiecznej geometrii i pozakrawędziowego wejścia co pozostałe fale.
- [x] Nazwa i stan każdego aktywnego bonusu są dostępne dla czytnika ekranu bez polegania na kolorze.
