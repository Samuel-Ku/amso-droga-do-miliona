# 10 — Opowiedzieć historię `10% budżetu → 7 lat`

**What to build:** Dostarczyć pięciokrokową animowaną historię firmy B2B, która zaczyna od ostrożnego testu, sprawdza urządzenia w pracy, realizuje resztę zakupu i po siedmiu latach nadal wybiera sprzęt poleasingowy.

Blocked by: 02

Status: ready-for-agent

- [x] Pierwszy krok pokazuje plan większego zakupu i realną wątpliwość klienta.
- [x] Testowe zamówienie jest opisane jako 10% przygotowanego budżetu, nie 10% urządzeń ani całej historii współpracy.
- [x] Pracownicy korzystają z testowych urządzeń przed decyzją o pozostałej części zakupu.
- [x] Po udanym teście firma realizuje resztę planowanego zakupu.
- [x] Kalendarz przechodzi o siedem lat, a finał mówi, że klient nadal wybiera sprzęt poleasingowy.
- [x] Copy nie twierdzi o nieprzerwanej siedmioletniej współpracy bez marketingowego potwierdzenia.
- [x] Sekwencja pozostaje w jednym środowisku i czeka na działanie gracza w każdym kroku.
