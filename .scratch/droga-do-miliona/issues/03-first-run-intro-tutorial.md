# 03 — Dodać first-run intro i interaktywny tutorial

**What to build:** Przeprowadzić nowego gracza od wyjaśnienia kampanii do pierwszej samodzielnej sekcji gry, ucząc wszystkich podstaw w bezpiecznym i niemożliwym do przegrania przebiegu.

Blocked by: 02

Status: ready-for-agent

- [x] Intro wyjaśnia drogę AMSO do miliona, przeplatanie historii z grą oraz bezpieczne momenty czytania.
- [x] Gracz wykonuje po jednym skoku i ślizgu, zbiera pierwszą paczkę i widzi wzrost licznika.
- [x] Samouczek nie może zakończyć się porażką ani przejść dalej bez wykonania wymaganych działań.
- [x] Pierwsze objaśnienia przeszkód, paczek, bonusów i combo są krótkie i sterowane przez gracza.
- [x] Pierwsze przejście trwa około 35–45 sekund przy standardowym tempie działania.
- [x] Powracający gracz otrzymuje skrót i akcję ponownego otwarcia pełnej instrukcji.
- [x] Obsługa dotyku, klawiatury, fokusu i komunikatów czytnika ekranu jest równoważna.
