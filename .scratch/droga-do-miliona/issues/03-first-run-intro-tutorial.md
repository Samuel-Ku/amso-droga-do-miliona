# 03 — Dodać first-run intro i interaktywny tutorial

**What to build:** Przeprowadzić nowego gracza od wyjaśnienia kampanii do pierwszej samodzielnej sekcji gry, ucząc wszystkich podstaw w bezpiecznym i niemożliwym do przegrania przebiegu.

Blocked by: 02

Status: ready-for-agent

- [ ] Intro wyjaśnia drogę AMSO do miliona, przeplatanie historii z grą oraz bezpieczne momenty czytania.
- [ ] Gracz wykonuje po jednym skoku i ślizgu, zbiera pierwszą paczkę i widzi wzrost licznika.
- [ ] Samouczek nie może zakończyć się porażką ani przejść dalej bez wykonania wymaganych działań.
- [ ] Pierwsze objaśnienia przeszkód, paczek, bonusów i combo są krótkie i sterowane przez gracza.
- [ ] Pierwsze przejście trwa około 35–45 sekund przy standardowym tempie działania.
- [ ] Powracający gracz otrzymuje skrót i akcję ponownego otwarcia pełnej instrukcji.
- [ ] Obsługa dotyku, klawiatury, fokusu i komunikatów czytnika ekranu jest równoważna.
