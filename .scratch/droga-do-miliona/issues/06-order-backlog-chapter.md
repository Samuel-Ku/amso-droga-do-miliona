# 06 — Zrealizować rozdział `Zator Zamówień`

**What to build:** Zamienić abstrakcyjny chaos kabli w fabularny i grywalny zator realnych zamówień, po którego ukończeniu ten sam magazyn przechodzi od improwizacji do widocznego procesu.

Blocked by: 02

Status: ready-for-agent

- [x] Przed wyzwaniem rosnąca liczba paczek, ręcznych etykiet i zadań tworzy czytelny zator w małym magazynie.
- [x] Wyzwanie używa kartonów, palet, wózków i stanowisk na wspólnej linii podłoża zamiast krzywych i kablowej istoty.
- [x] Skok i ślizg są potrzebne w kilku zapowiedzianych, osiągalnych kombinacjach.
- [x] Po ukończeniu te same elementy trafiają do stref `PRZYJĘCIE`, `KONTROLA`, `PAKOWANIE`, `WYSYŁKA`.
- [x] Finałowy tekst wyjaśnia, że wzrost wymusił zamianę improwizacji w powtarzalny proces.
- [x] HUD, copydeck i dostępne komunikaty używają wyłącznie nazwy `Zator Zamówień`.
- [x] Rozdział jest demoowalny jako pełna sekwencja scena → gameplay → fabularny skutek.
