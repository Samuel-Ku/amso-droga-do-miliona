# 05 — Etalonowy zestaw assetów zamówień i power-upów

**What to build:** Powstaje spójny, produkcyjny zestaw wizualny wszystkich przedmiotów zbieranych podczas gry: czterech kategorii sprzętu, pomarańczowej paczki i dwóch jednoznacznych power-upów.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Notebook, telefon, zestaw PC i LCD zachowują zatwierdzony styl: zaokrąglone bryły, szare kontury, jasnoniebieskie ekrany i oszczędne refleksy.
- [ ] Każde urządzenie powstaje jako osobny przezroczysty WebP na wspólnym płótnie 256×256 z identycznym wizualnym środkiem.
- [ ] Pomarańczowa paczka z białymi taśmami ma spójny zestaw kolejnych ujęć umożliwiających płynny obrót.
- [ ] `Gwarancja 48 M` otrzymuje ilustracyjny shield, a `2× WYNIK` czytelny przestrzenny znak `2×` w tej samej jakości materiału.
- [ ] Power-upy są rozpoznawalne bez drobnego tekstu i nie wyglądają jak zwykłe urządzenie albo paczka.
- [ ] Wszystkie assety pozostają czytelne przy docelowym rozmiarze około 38–44 px.
- [ ] Wspólny atlas nie zmienia proporcji lub skali poszczególnych przedmiotów.
- [ ] Review gallery pokazuje każdy asset osobno, w docelowym rozmiarze i na reprezentatywnym tle gameplay.
- [ ] Produkcyjne pliki są niezależnymi ilustracjami; concept sheet i referencje nie są wycinane bezpośrednio jako finalne assety.
