# 01 — Etalonowy prototyp historii klienta

**What to build:** Osobny, interaktywny prototyp historii klienta, który rozpoczyna działalność z budżetem do 400 zł, wybiera laptop za 300 zł i po roku wraca z budżetem 100 000 zł. Prototyp ma udowodnić, że przedmiotowy, wielowarstwowy język SVG jest czytelny przed przebudową production flow.

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [x] Prototyp działa poza production flow i nie zmienia zachowania głównej gry.
- [x] Historia wykorzystuje jednego konsekwentnie wyglądającego, anonimowego klienta oraz ten sam pierwszy laptop we wszystkich krokach.
- [x] Sekwencja pokazuje kolejno budżet do 400 zł, wybór laptopa za 300 zł, upływ roku i powrót z budżetem 100 000 zł.
- [x] Każdy krok odtwarza jedną animację przez 1,5–3 sekundy i zatrzymuje się w czytelnym stanie końcowym.
- [x] Desktop i wariant 390 px pokazują całą główną czynność oraz jej rezultat bez przypadkowego kadrowania.
- [x] Prototyp nie używa abstrakcyjnych ramek, swobodnych linii ani figur bez jednoznacznego znaczenia.
- [x] Gradient wskazuje wyłącznie aktywny przepływ, sukces, postęp albo kulminację.
- [x] Tekst i liczby są oddzielone od geometrii ilustracji i można je edytować bez zmiany SVG.
- [x] Tryb ograniczonego ruchu pokazuje te same stany końcowe bez intensywnej animacji.
