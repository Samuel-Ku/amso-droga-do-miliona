# 06 — Historia rozwoju klienta i wyzwanie wzrostu

**What to build:** Zintegrowana historia jednego klienta oraz jedno powiązane wyzwanie, które pokazują przejście od pierwszego laptopa do rozwijającej się firmy bez udawania mechaniki wyboru sprzętu.

**Blocked by:** 01 — Etalonowy prototyp historii klienta; 02 — Bezpieczne wejście do karty i sterowanie jedną ręką; 03 — Storyboard i pięciominutowy kontrakt fabuły v6.

**Status:** ready-for-human

- [x] Zatwierdzone warstwy i stany prototypu działają w production flow.
- [x] Historia zachowuje fakty: start działalności, budżet do 400 zł, laptop za 300 zł i powrót po roku z budżetem 100 000 zł.
- [x] Jeden anonimowy klient i pierwszy laptop zapewniają wizualną ciągłość wszystkich kroków.
- [x] Pozostałe historie są krótkim montażem wielu planów i nie wyglądają jak dalszy ciąg głównego klienta.
- [x] Trzy dotychczasowe wyzwania dopasowania zostają zastąpione jednym segmentem wzrostu.
- [x] Zbierane elementy kolejno budują pierwszy laptop, stanowisko pracy i wyposażenie zespołu w stanie końcowym.
- [x] Nazwa, HUD i rezultat segmentu opisują rozwój firmy, a nie wybór, którego mechanika nie oferuje.
- [x] Segment zachowuje skok, `S`/`↓` jako ślizg oraz bezpieczne zasady fabuły.
- [x] Desktop, 390 px, reduced motion, manifest i pełny lifecycle przechodzą testy.
