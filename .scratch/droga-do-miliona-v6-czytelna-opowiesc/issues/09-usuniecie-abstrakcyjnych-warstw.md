# 09 — Usunięcie abstrakcyjnych warstw i ciągłość świata

**What to build:** Kontrakt starej warstwy wizualnej po zakończeniu migracji: gra i challenge używają wyłącznie nowych, przedmiotowych stanów, a wszystkie bezfunkcyjne figury i osierocone treści zostają usunięte.

**Blocked by:** 04 — Pierwsza paczka, zator i uporządkowany proces; 05 — Próba Jakości i drugie życie sprzętu; 06 — Historia rozwoju klienta i wyzwanie wzrostu; 07 — Skala telefonów i porównanie z PKiN; 08 — Próg Miliona i przejście do challenge.

**Status:** ready-for-human

- [x] Wszystkie aktywne kroki fabuły mapują się jeden do jednego na zatwierdzone, przedmiotowe stany świata.
- [x] Nieaktywne abstrakcyjne ramki, swobodne linie, puste kwadraty i geometryczne nakładki zostają usunięte z produkcyjnych zasobów oraz fallbacków.
- [x] Każdy pozostawiony element ma udokumentowaną rolę przedmiotu, osoby, czynności, trasy, stanu albo wyniku.
- [x] Challenge cyklicznie pokazuje wyłącznie pozytywne finalne stany nowych światów.
- [x] Żaden stan challenge nie przywraca usuniętych historii klientów ani porównania z Boeingami.
- [x] Wszystkie światy pozostają jasne, osadzone na spójnej płaszczyźnie i poprawnie kadrowane od 390 px do kontenera desktopowego.
- [x] Zasoby i fallbacki działają także przy niedostępności opcjonalnych obrazów.
- [x] Test manifestu odrzuca brakujący stan, osierocony świat, brak kamery mobilnej lub nieznaną warstwę krytyczną.
- [x] Pełny audyt obejmuje wszystkie aktywne sceny, a nie tylko pięć pierwotnie zgłoszonych kadrów.
