# 05 — Próba Jakości i drugie życie sprzętu

**What to build:** Kompletny rozdział serwisowy, w którym urządzenie trafia na stanowisko, przechodzi czytelny proces przygotowania, otrzymuje status `SPRAWDZONY` i wraca do obiegu.

**Blocked by:** 01 — Etalonowy prototyp historii klienta; 02 — Bezpieczne wejście do karty i sterowanie jedną ręką; 03 — Storyboard i pięciominutowy kontrakt fabuły v6.

**Status:** ready-for-human

- [x] To samo urządzenie pozostaje widoczne od przyjęcia do gotowej paczki.
- [x] Stanowisko, pracownik, urządzenie, oznaczenie i opakowanie mają jednoznaczne sylwetki i role.
- [x] Postęp jakości jest przedstawiony przez czynności na urządzeniu, a nie przez puste checkboxy lub figury ostrzegawcze.
- [x] `SPRAWDZONY` pojawia się jako wynik ukończonego procesu i pozostaje treścią edytowalną poza geometrią obrazu.
- [x] Finał rozdziału pokazuje przygotowane urządzenie wysyłane do kolejnego użytkownika.
- [x] Animacje odtwarzają się raz, zatrzymują się w stanie końcowym i mają równoważny wariant reduced motion.
- [x] Kurier nie jest bohaterem scen czytania.
- [x] Desktop i 390 px zachowują urządzenie, czynność i wynik w bezpiecznym kadrze.
- [x] Rozdział przechodzi testy konfiguracji, manifestu, dostępności i odpowiedniego fragmentu lifecycle.
