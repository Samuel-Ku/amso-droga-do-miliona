# 03 — Storyboard i pięciominutowy kontrakt fabuły v6

**What to build:** Pełny, możliwy do przejścia tekstowo production flow v6, który opowiada drogę AMSO w około czternastu krokach, zachowuje pięć minut do miliona i daje marketingowi aktualny materiał do równoległej redakcji.

**Blocked by:** 01 — Etalonowy prototyp historii klienta.

**Status:** ready-for-human

- [x] Storyboard obejmuje około czternastu kroków: początek, zator i proces, jakość, jedną główną historię klienta, skalę oraz finał.
- [x] Każdy krok zawiera jeden fakt, jedną znaczącą czynność i opis jednego finalnego kadru.
- [x] Główną osią pozostaje droga AMSO; historia klienta jest przykładem wpływu, a pozostałe historie tworzą krótki montaż.
- [x] Dwie historie biznesowe pozostają jednoznacznie rozdzielone i nie są przedstawiane jako jeden klient.
- [x] Production flow zawiera szkolenie, `Zator Zamówień`, `Próbę Jakości`, jedno wyzwanie rozwoju klienta, `Szczyt Zamówień` i `Próg Miliona`.
- [x] Skonfigurowana aktywna rozgrywka trwa około 3–3,5 minuty, a standardowy odbiór scen prowadzi do miliona w około 5 minut bez limitowania czytania.
- [x] Nagłówek każdego kroku ma maksymalnie 7–8 słów, a tekst główny nie przekracza 220 znaków i celuje w około 180 znaków.
- [x] Porównanie z PKiN pozostaje w aktywnym flow, a porównanie z Boeingami nie występuje w głównej grze.
- [x] Marketingowy CSV eksportuje wyłącznie aktywne kroki v6, ich limity, fakty, perspektywę i pola decyzji.
- [x] Pełny lifecycle-test przechodzi nową sekwencję od pierwszej paczki do challenge, zachowując wynik i bezpieczne zasady fabuły.
