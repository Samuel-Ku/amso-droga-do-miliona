# 07 — Skala telefonów i porównanie z PKiN

**What to build:** Jedna czytelna sekwencja skali, która wyjaśnia roczną liczbę telefonów, buduje z nich porównanie wysokości i wraca do ludzi oraz logistyki stojących za wynikiem.

**Blocked by:** 01 — Etalonowy prototyp historii klienta; 02 — Bezpieczne wejście do karty i sterowanie jedną ręką; 03 — Storyboard i pięciominutowy kontrakt fabuły v6.

**Status:** ready-for-human

- [x] Scena najpierw podaje około 28 000 telefonów oraz jednoznacznie wskazuje okres roczny.
- [x] Telefony tworzą czytelną pionową skalę około 240 metrów obok rozpoznawalnego siluetu PKiN.
- [x] Liczba, okres i podpis porównania pozostają edytowalną i dostępną treścią, nie tekstem wypalonym w grafice.
- [x] Porównanie z Boeingami nie występuje w aktywnej fabule, świecie challenge ani aktywnym eksporcie copy gry.
- [x] Sekwencja kończy się widokiem zespołu, magazynu i rzeczywistych wysyłek, aby liczby nie pozostały oderwaną infografiką.
- [x] Gradient wskazuje tylko budowanie skali lub osiągnięcie porównania.
- [x] Desktop i 390 px pokazują telefony, miarę i PKiN w jednym zrozumiałym kadrze.
- [x] Reduced motion otrzymuje ten sam finalny układ bez intensywnego ruchu.
- [x] Testy treści, manifestu, dostępności i lifecycle potwierdzają właściwy fakt i kolejność.
