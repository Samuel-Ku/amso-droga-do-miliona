# 07 — Próg Miliona — finał bez bossa

**What to build:** Najbardziej różnorodny i intensywny fragment fabuły, w którym gracz wykorzystuje wszystkie poznane umiejętności, fizycznie zbiera ostatnie zamówienia i doprowadza licznik dokładnie do miliona bez walki z bossem.

**Blocked by:** 04 — Proces i Jakość — cztery urządzenia i AUDYT; 05 — Rozwój Firmy Klienta — trzy fazy i DRUGIE ŻYCIE; 06 — Skala Zamówień — przyjęcie, realizacja i wysyłka.

Status: ready-for-human

- [x] Model bossa, pasek życia, wózek widłowy i ataki bossa nie są częścią finału ani jego prezentacji.
- [x] Finał ma dwanaście autorskich kombinacji wykorzystujących pojedyncze akcje, dublety, trzyakcjowe serie, długie łuki, nagradzające cisze i uczciwie zapowiedziane zmiany tempa.
- [x] Identyczny wzór nie występuje bezpośrednio po sobie, każda intensywna seria ma odpoczynek, a pozorny odpoczynek nie ukrywa przeszkody.
- [x] Pierwsza akcja ma co najmniej 1,6 sekundy zapowiedzi, dalsze akcje serii są widoczne z wyprzedzeniem, a wszystkie przejścia są fizycznie wykonalne.
- [x] Cel paczek jest konfigurowalny w zakresie 40–60, z domyślną wartością 50.
- [x] Początek licznika jest automatycznie wyliczany jako 1 000 000 minus cel; dla 50 paczek wynosi 999 950.
- [x] Każda zebrana finałowa paczka zwiększa licznik dokładnie o jeden, a pominięta wraca w późniejszej bezpiecznej strefie.
- [x] Sam licznik jest semantycznym celem finału; nie pojawia się drugi abstrakcyjny pasek postępu.
- [x] Po osiągnięciu miliona gameplay trwa jeszcze kilka sekund na nagradzającej trasie, zanim rozpocznie się celebracja i jawna zmiana trybu.
- [x] Cztery akty finału stopniowo wzmacniają rytm, warstwy audio i wizualny rezultat, bez zasłaniania trasy.
- [x] Testy potwierdzają cele 40, 50 i 60, dokładną inkrementację, powrót pominiętych paczek, dwanaście kombinacji, brak powtórzeń oraz brak bossa i wózka.
