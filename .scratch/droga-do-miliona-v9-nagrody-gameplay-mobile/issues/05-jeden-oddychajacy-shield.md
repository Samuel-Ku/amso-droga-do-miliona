# 05 — Jeden duży, oddychający shield Gwarancji

**What to build:** Gracz rozpoznaje realną ochronę po jednym dużym pomarańczowym kole, które zachowuje rozmiar w każdej pozie i subtelnie oddycha. Start, aktywna `GWARANCJA 48 M` i jej zużycie korzystają z jednej logicznej historii wizualnej.

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [ ] Jednocześnie renderowany jest dokładnie jeden shield bez dodatkowego pierścienia, haczyków, promieni ani linii.
- [ ] Shield ma stały bazowy rozmiar i położenie względem całej sylwetki kuriera podczas biegu, skoku i przysiadu.
- [ ] Oddech trwa około 1,8–2,0 s, zmienia promień najwyżej o 1,5 px i subtelnie moduluje pomarańczowy blask.
- [ ] Grubość głównego konturu pozostaje stała i nie tworzy efektu dwóch okręgów.
- [ ] Startowa niewrażliwość pokazuje samo koło bez dodatkowego znaku lub stałego wpisu bonusu.
- [ ] Zebranie Gwarancji krótko komunikuje `GWARANCJA`, a aktywna ochrona pozostaje widoczna jako to samo koło.
- [ ] Pochłonięta kolizja uruchamia jeden czytelny efekt pęknięcia, po którym shield i ładunek znikają.
- [ ] Shield nie pojawia się, gdy silnik nie pochłonie następnego zderzenia.
- [ ] W `reduced motion` informacja pozostaje czytelna bez intensywnego oddechu i animowanego pękania.
