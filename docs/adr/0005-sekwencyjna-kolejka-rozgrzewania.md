# Sekwencyjna kolejka rozgrzewania assetów

Autonomiczny HTML będzie dekodował assety etapami: minimalny zestaw ekranu startowego przy otwarciu, krytyczny zestaw gameplayu po wybraniu Start, a następnie po jednym tle świata podczas bezczynności albo pauz fabularnych. AudioContext powstanie dopiero po pierwszym geście użytkownika; krytyczne sygnały dźwiękowe otrzymają pierwszeństwo, lecz ich brak nie zablokuje rozgrywki. Nie będzie równoległego dekodowania wszystkich osadzonych obrazów ani audio. Takie planowanie zachowuje samowystarczalność jednego pliku, ogranicza skoki CPU i pamięci podczas startu oraz pozwala wypełniać Pamięć światów bez blokowania aktywnej rozgrywki; kosztem jest jawna kolejka i konieczność priorytetyzacji assetów wymaganych przy bezpośrednim wejściu do Trybu Wyzwania.
