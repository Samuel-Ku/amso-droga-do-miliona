# Zachowanie symulacji gameplayu 120 Hz

Optymalizacja wydajności najpierw obejmie rendering, parallax i zarządzanie assetami, a istniejąca symulacja fizyki oraz kolizji pozostanie przy 120 Hz. Obniżenie częstotliwości mogłoby zmienić responsywność i uczciwość zatwierdzonego gameplayu; można do niego wrócić tylko wtedy, gdy Raport wydajności wykaże, że update-loop stale zużywa ponad 25% budżetu klatki, a zmiana przejdzie ponowny gameplay QA.
